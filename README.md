# magicpin Vera AI Challenge — two head-to-head bots

| Bot | Live URL | Strategy |
|---|---|---|
| `vera-signal/` | https://vera-signal.vercel.app | rank the strongest merchant signal → one Groq call → grounding validator |
| `vera-planner/` | https://vera-planner-two.vercel.app | plan → 3 lever drafts → rubric + Groq critic → pick |

- `shared/vera/` — common engine (facts, trigger plans/templates, validator, reply state machine, Groq client, Redis store, API). Copy into both bots with `./sync_shared.sh`.
- `tests/harness.py` — end-to-end test: `python tests/harness.py signal|planner [--url <live url>]`.
- Challenge starter pack: `challenge-brief.md`, `challenge-testing-brief.md`, `dataset/`, `examples/`, `judge_simulator.py`; `expanded/` generated by `dataset/generate_dataset.py`.

Deploy: `./sync_shared.sh && (cd vera-signal && vercel deploy --prod) && (cd vera-planner && vercel deploy --prod)`.
Env (Vercel): `GROQ_API_KEY`, Upstash `KV_REST_API_URL`/`KV_REST_API_TOKEN`, `TEAM_NAME`, `TEAM_MEMBERS`, `CONTACT_EMAIL`.
